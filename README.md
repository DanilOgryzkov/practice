# Git Practice

Практическое задание по Git и GitHub.

## Цель

Научиться создавать коммиты, ветки, Pull Request и выполнять слияние изменений.
## Выполненные действия

- Создан репозиторий.
- Созданы коммиты в ветке main.
- Будет создана отдельная ветка.
- Будет открыт Pull Request.
